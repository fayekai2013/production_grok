# Knowledge Router: Film Production Knowledge Library v1

How to use this: find the problem you have, open the topic's STUDY_NOTES_EN.md at the section listed, and go to the original source only when you need exact wording. Notes tag every claim **[Source]**, **[Owner study]** or **[Ours]** (our inference, untested unless stated). The library holds know-how, not golden rules: each item says when to use it and what it costs.
