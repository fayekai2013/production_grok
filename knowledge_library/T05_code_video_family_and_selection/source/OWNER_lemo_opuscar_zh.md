## 一句話概念

給 Claude Code 用的影片風格庫：風格不寫成參數化模板，而是用 prompt 把導演、鏡頭與風格語言講清楚，讓模型用程式碼（2D/3D 繪製與剪輯）把片子做完。這次更新把定位從「選風格的庫」推進成「製作自己風格的工具箱」。

## 核心設計哲學（作者自述，值得注意）

- 風格即 prompt：不規定技術與數值，只告訴模型「你可以做什麼」和「我想要什麼」。理由是模型會持續進化，把效果寫死成參數會鎖住模型能力，要「向前開發」。
- 代價作者自己承認：綁定 Claude 系模型的能力，換成 Codex 等其他模型效果可能明顯較差。
- 檔位實測（作者）：新創風格用 Opus High 或 XHigh，做片可用 Sonnet High，三個檔位最穩定。

## 風格庫現況（59 種，目標 99）

分類包括：剪輯與紀實（本次新增 8：字幕新聞、1920s 新聞影片、即時倒數分屏、延時交響、視覺調查、構成主義蒙太奇、體育戰術板、電視新聞包裝）、實證影像（8）、手繪與繪畫（7）、東方傳統（4）、印刷與版畫（5）、圖形與排版（7）、資訊與發布（5）、卡通與動畫（4）、遊戲（4）、電影與時代（2）、材質與 3D（5）。另有 Opuscar98 的 98 種長篇風格提示詞全部公開。

本次新增 8 種的共同點：不再靠程式碼作畫，而是用真實素材（影像、照片、文件、數據）按某種剪輯與包裝語法排好再配聲，指向新聞、紀實、自媒體用途。

## 新玩法：把風格改成自己的（本次更新核心）

入口四種：用庫裡風格做片、改一個庫裡風格存成自己的、從空白開始做自己的、用已存的自己風格做片。流程：

1. 更新或安裝 plugin（`claude plugin marketplace add lemomo-ai/lemo-opuscar`）
2. 選入口；從空白開始時，先由 Claude 從庫裡挑最接近的風格當「技法底子」並說明理由
3. 一次問一個問題定方案（約十題，每題選項附推薦與理由，可隨時說「你定」或切換自由對話）。問的順序：用途與平台規格、品牌色/logo/字體/固定角色、想改哪裡、逐項細問（材質、配色、字體、動態、鏡頭、聲音、標誌鏡頭）、命名
4. 改動分三級講清楚：放心改（配色、字體、速度、聲音、標誌鏡頭）、一改就變味（材質與畫法、配色邏輯、鏡頭語法，會告知代價）、不能改（風格本質與底層引擎，改了就是另一種風格）
5. 彙總方案（改前、改後、代價）讓使用者點頭才寫下
6. 先出風格圖：用真實繪製程式碼出圖，改版風格會把原版同畫面並排對照；兩輪還不對就直說並建議換底子
7. 做 15 到 30 秒 demo 片驗證風格成立（每處改動至少出現一次，含音樂音效，自檢修一輪再交，註明每處改動出現的秒數）
8. 滿意後固化成自己的風格（MY-STYLES），下次啟動排最前面；也可以投稿回官方庫
