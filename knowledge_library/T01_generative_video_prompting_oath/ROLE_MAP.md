# ROLE_MAP — T01 Generative video prompting (The Oath method)

| Role | Needs it for | Read first |
|---|---|---|
| Lead | Approving the stills-before-video gate; explaining to stakeholders why sheets and keyframes come first; take budgets | §1, §6 |
| Script & Story | Shot lists with shot size / lens / move / action / exact dialogue, so the script hands off cleanly to prompts | §2 steps 1–2 |
| Casting & Reference | Character/product sheet prompts (three-panel grey layout, signature detail with fixed side, identity-lock sentence); one sheet per look | §3.1, §7 sheet skeleton |
| Previs & Motion | IMAGE 1/2/3 timeline threading, middle-keyframe timing, FRAME LEFT/CENTER/RIGHT + depth positions, camera default (locked) vs handheld peak | §3.2, §4 rules 3, 5–7, §3.3 |
| Generation & Edit | Writing the 7-block video prompt; CRITICAL secondary motion; physics; audio negatives; constraints restatement; shorten-on-failure retries; edit/sound budget | §3.2, §4, §5, §7 |
| Measurement & QC | Knowing which failures map to which fix (identity → sheet; composition → keyframe; timing → middle frame; camera drift → negative list); residual face drift is expected | §5, §8 |
| Recorder & Playbook | Keeping the verbatim example prompts and the 12 techniques as the canonical prompting reference; logging which retry tactic fixed what | §3, §4 |
